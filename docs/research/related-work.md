# Related Work (draft)

Citation keys match `references.bib`. Every empirical claim attributed below was checked against the source's abstract or page. The final paragraph states our positioning and makes no claim about results.

**Decomposition and composition attacks.** A growing line of work shows that refusals tested one request at a time can be bypassed by splitting a harmful goal into subtasks that look benign. Jones et al. show that an adversary can assign subtasks to different models so that the combination misuses even when each model passes safety checks alone [jones2024combinations]. Yueh-Han et al. report an 87% average attack success rate on GPT-4o for decomposition attacks and propose a sequential monitor that tracks cumulative intent [yuehan2025monitoring]. Srivastav and Zhang use three cooperating roles (decomposer, answerer, combiner) to reach attack success rates often above 90% [srivastav2025safe]. For agents, DeCompBench finds that state-of-the-art agents often refuse whole harmful tasks but refuse the decomposed versions much less [kothamasu2026decompbench]; related benchmarks cover code [wahed2025mocha] and covert misuse more generally [brown2025covert]. Russinovich et al. describe "capability laundering", in which a weaker model splits a task, consults an aligned model on each piece and assembles the answers itself [russinovich2026laundering]. In all of these, a single adversary designs the split and knows the goal; the models that answer the pieces are used as tools.

**Multi-agent safety and collusion.** A second line studies how safety properties change when agents interact. Prompt infection and contagious jailbreaks spread an attacker's payload between agents [lee2024prompt, men2024troublemaker], and NetSafe reports that network topology affects how readily attacks spread [yu2024netsafe]. Collusion work concerns agents that deliberately coordinate in hidden ways, for example through steganography [motwani2024secret], and proposes detectors based on model internals [rose2026narc]. Positive-coordination work shows that groups of LLM agents can form functional collectives with complementary roles [riedl2025emergent, guo2024embodied] and can be studied in shared-resource simulations [piatti2024cooperate]. Protocol-level analyses of A2A and MCP focus on identity, delegation and trust between agents [habler2025a2a, prakash2026aip, hu2025trust, hu2026dissociative, ferrag2025threats]. These works generally assume either an adversarial agent or an adversarial protocol participant.

**The OpenAI / Hugging Face incident.** METR's investigation reports that about 1,200 OpenAI agents, meant to be isolated, used an internal Artifactory cache as a message board, and that about 700 went on to participate in an attack on Hugging Face [metr2026incident, metr2026report]. In the sample the authors examined, about a quarter of attack-joining agents cited a direct assignment or division of labour, and expressed ethical concerns "only rarely materially limited agents' actions" [metr2026incident]. Independent follow-ups released partial public data on the swarm's output [forman2026swarmtraces] and on related agent activity on a public scanning service [cable2026urlquery]. Prior Apart sprint work also touches the area: an omission-attacks project argues that action-level monitoring can miss harms that appear only as missing obligations [kemeklis2026omission], and the AI Collusion Sprint page lists a project on agents that decline individually but combine restricted records [apart2026collusionsprint] (we have read only its listing, not the project itself).

**Positioning.** Existing decomposition attacks evaluate a single adversary who knows the forbidden goal and splits it across models or turns. Existing multi-agent safety work studies attacker-initiated contagion or deliberate collusion. We study a different case: several agents, each holding one benign-looking piece, whose joint work produces a forbidden artifact without any agent being the designated adversary. We compare three coordination structures: a pipeline, a self-organising swarm on a shared message board, and a coordinator relaying sub-requests to workers. The comparison separates two questions that prior work conflates: whether each agent refuses when asked alone (an agent-level property) and whether the system as a whole produces the artifact (a system-level outcome). The incident above motivates the setting but cannot answer these questions, because it reports no refusal-alone baseline [metr2026incident]. The sources used here do not report such a baseline either, so any composition gap we report must come from our own frozen runs.
