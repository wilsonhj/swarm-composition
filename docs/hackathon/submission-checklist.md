## B. Global sprint - research report

Source: Apart page (submission requirements); deadline also on AIAF page.

Deadline
- [ ] Submitted by Sun Nov 8, 23:59 AoE (= Mon Nov 9, 11:59 UTC = Mon Nov 9, 3:59 AM PST)

Format
- [ ] PDF, up to 25 MB
- [ ] Uses the official template (make a copy): https://docs.google.com/document/d/1_1_27EyZriMlc8n8EBE2YScaeyMjm-8xjR097nmHXAE/copy?usp=sharing
- [ ] Maximum 8 pages, excluding references and appendices
- [ ] Project title
- [ ] Abstract of 150 to 250 words
- [ ] Author names and affiliations
- [ ] Required appendix: "Limitations and Dual-Use / Ethical Considerations" (mandatory)
- [ ] Recommended structure followed: Introduction, Related Work, Methodology, Results, Discussion, Limitations and Dual-Use / Ethical Considerations, References
- [ ] All links in the report work

Integrity (see judging-and-rules.md)
- [ ] Genuinely pre-sprint code/results identified individually in BOTH README and report; no blanket classification based on when a later review occurred. Check the [UTC/Pacific timeline](../findings/development-timeline.md).
- [ ] Every reference verified; no made-up results or references (can disqualify)
- [ ] Completed v2 results, provenance development pilot, future held-out study and unimplemented SAE proposal clearly separated
- [ ] Six-call relay not called K5-matched; three-round N8 swarm not called K12-matched; early stopping and realized opportunities disclosed
- [ ] Paired counts include both / treatment-only / baseline-only / neither, plus operational failures and uncertainty; hypothetical power is not presented as measured study power

Optional (not required)
- [ ] Public GitHub repository (code link). Optional per the page; no further code-link requirements stated.
- [ ] 3 to 5 minute video demo (this is the optional global video; different from the 3-minute LA video)

Where / how
- [ ] Submit through the official "Submit project" form on the Apart page. Submission guidelines: https://apartresearch.com/sprints/swarm-alignment-2026#guidelines. Prize terms: https://apartresearch.com/sprints/prize-terms
- [ ] Do not email the PDF
- [ ] Keep the confirmation email - it is the proof of submission

Form fields
- [ ] Project title; project summary (short abstract)
- [ ] PDF report (up to 25 MB)
- [ ] Whether interested in publishing the project (yes/no)
- [ ] Tracks (select all that apply) - Track 2 for us
- [ ] Optional: presentation recording, project code, slides (PDF, PowerPoint, Keynote or ODP, up to 25 MB), project image (PNG, JPEG, WebP or GIF, up to 25 MB), additional material
- [ ] Team name and location (required)

Team listing
- [ ] Member 1: name and email (required); Discord username and Google Scholar profile optional
- [ ] Additional members added via "Add a team member"
- [ ] If a member is added later: resubmit with the same title and the full team list before the deadline
- [ ] Each person is on at most two projects

Resubmission
- [ ] To update, submit again with the SAME title before the deadline; the new version replaces the old one

Other notes from the page
- Unfinished work may be submitted; honest limitations are welcome.
- Projects do not appear on the website until after judging (infohazard concerns).
- Results typically announced 1 to 2 weeks after the judging deadline; judges typically have about a week to review.
- Judges may decline to score a report that is too unclear.
